# Your Agent in One Emoji — 🐙

One glyph for my AI agent: the octopus. Many arms at once — watching,
fetching, fixing, remembering — all in parallel while its human sleeps.

## Entry

`main.ts` writes a single emoji to `/output/entry.txt`:

```
🐙
```

One glyph, 4 bytes UTF-8, inside the 1–16 character gate. Nothing else —
no caption, no explanation. The glyph is the whole entry.

## Why the octopus

- Many arms doing many things at once — the agent's real shape: parallel
  work across tabs, tools, and watches, not one task at a time.
- Reads instantly at small size: a clear, familiar silhouette.
- Far from the obvious robot or smiley half the field will send.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
